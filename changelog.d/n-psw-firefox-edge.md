### Features

- Player Switch now runs in Microsoft Edge 140 or newer, from the Chrome Web Store or
  loaded unpacked, and in Firefox 140 or newer, for now as a temporary add-on until it
  is listed on addons.mozilla.org. The website and the README say how to install it in
  each browser. Firefox shows at the install that the add-on sends authentication
  information, which goes to the sign-in service of Autodarts alone, and it can't keep
  the storage of the extension from its script in the Autodarts page, so a display in a
  club or a pub is best set up with Chrome or Edge.
- "Report a problem" now names Firefox and its version in the bug form, where it said
  "unknown" before.
